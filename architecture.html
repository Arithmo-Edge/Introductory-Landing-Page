04 · Dual-Storage Hybrid Data Lake

Hot Cloud Firestore + Cold 24-Hour Private GitHub Zero-PII JSONL Lake

Hot Storage Layer · Real-Time State

Unified Cloud Firestore

Handles sub-second live match scores, 14 real-time leaderboards, active `1v1 Bullet Blitz` rooms, `Arithmo Wallet` ledger transactions, `donors` Patron Wall webhooks, and live clarifications during active 100-minute contests.

Cold Storage Layer · Automated 24h GitHub Actions

Private Zero-PII JSONL Data Lake

Every 24 hours, automated GitHub Actions strip all PII (emails, legal names, IPs), flush historical submissions, `MBTS` telemetry, and `Find the Flaw` traces into compressed `.jsonl` shards inside a private GitHub repository—keeping Firestore read/write footprints minimal while feeding AI model calibration.
